## Wat is BTW mapping?

BTW mapping vertelt Omniboost welke tax code in je boekhoudsysteem overeenkomt met welk belastingtarief in Mews. Bijvoorbeeld: Mews kan een 21 procent BTW categorie hebben voor overnachtingen. Die moet je koppelen aan de juiste 21 procent BTW code in je boekhoudsoftware zodat de belasting op de juiste plek wordt geboekt.

## De belangrijkste regel: halen uit BRUTO

Als je BTW codes instelt in Omniboost, zorg er absoluut voor dat ze geconfigureerd zijn om BTW uit het brutobedrag te HALEN en niet om BTW bij het nettobedrag OP TE TELLEN. Deze twee aanpakken leveren verschillende resultaten op. Als een gast 121 EUR betaalt voor een kamer (100 EUR netto plus 21 EUR BTW tegen 21 procent), is de juiste aanpak om 21 EUR uit het brutobedrag van 121 EUR te halen. Als je het per ongeluk configureert om 21 procent bij het netto op te tellen, bereken je een ander BTW bedrag en is je belastingaangifte fout.

## Zo controleer je je BTW code configuratie

Controleer in je boekhoudsysteem de instellingen voor elke BTW code die je gebruikt. Er zou iets moeten staan als inclusive of extract from gross, niet exclusive of add to net. Als je het niet zeker weet, vraag het je boekhouder of de support van je boekhoudsoftware. Zodra het in je boekhoudsysteem correct is ingesteld, vul je de code gewoon in de Omniboost mapping in.

## Meerdere BTW tarieven

Hotels hebben meestal meerdere BTW tarieven: overnachtingen kunnen onder een verlaagd tarief vallen, food and beverage onder het standaardtarief, en sommige posten kunnen nul procent hebben. Elke categorie in Mews heeft zijn eigen BTW code nodig die aan het bijbehorende tarief in je boekhoudsysteem is gekoppeld. Gebruik geen verzamel BTW code voor alles.

## Wat gebeurt er als een BTW code ontbreekt?

Als een Mews categorie geen BTW code heeft gekoppeld in Omniboost, wordt de belasting voor die categorie niet correct geboekt. Afhankelijk van je setup kan het in een fallback rekening belanden of een boekingsfout veroorzaken. Zorg er altijd voor dat elke omzetcategorie zowel een omzetrekening ALS een BTW code heeft toegewezen.
