## Qu'est-ce qu'un compte fallback ?

Un compte fallback est un filet de sécurité. Parfois, une catégorie de revenu ou de paiement dans Mews n'a pas de code de compte assigné, soit parce qu'elle a été ajoutée récemment et que personne ne l'a encore mappée, soit parce que le mapping a été supprimé par erreur. Sans fallback, Omniboost ne parviendrait pas à enregistrer cette entrée et vous auriez un trou dans votre comptabilité. Avec un fallback, Omniboost envoie l'entrée sur le compte fallback à la place, afin que le total reste équilibré. Le montant est simplement au mauvais endroit temporairement.

## Vous devriez avoir deux comptes fallback

Omniboost recommande de créer au moins deux comptes fallback séparés : un pour le revenu (afin que les revenus non mappés atterrissent dans la bonne catégorie) et un pour les paiements (afin que les paiements non mappés atterrissent dans la bonne catégorie). Si vous les mélangez dans un seul compte, il est plus difficile de voir ce qui a mal tourné.

## Que faire lorsque vous voyez des montants sur les comptes fallback

Si vous remarquez des montants qui apparaissent sur vos comptes fallback dans votre système comptable, cela signifie qu'Omniboost n'a pas pu trouver un mapping pour ces entrées. Allez dans la configuration de mapping du portail Omniboost et trouvez quelles catégories n'ont pas de code de compte. Une fois les bons codes assignés, les futures entrées iront au bon endroit. Pour les entrées passées qui ont atterri dans le fallback, vous devrez peut-être effectuer une correction manuelle dans votre système comptable.

## Comptes fallback vs. comptes suspense

Un compte fallback intercepte les catégories non mappées. Un compte suspense est utilisé intentionnellement pour les paiements : c'est un compte d'attente temporaire pour un paiement qui a été enregistré dans Mews mais pas encore compensé par la banque. Les deux existent pour des raisons différentes.
