## Mews est un système de gestion hôtelière

Mews est un Property Management System (PMS) basé dans le cloud. Un PMS est le logiciel qu'un hôtel utilise pour tout gérer : prendre les réservations, effectuer les arrivées et départs, suivre les chambres occupées, gérer les paiements, faire tourner le restaurant ou le bar et produire les rapports financiers. Mews alimente plus de 15 000 hôtels dans 85 pays et a été élu meilleur PMS en 2024, 2025 et 2026 par Hotel Tech Report.

## Ce que Mews enregistre pour la comptabilité

Chaque fois qu'un client consomme quelque chose dans votre hôtel, une nuit, un petit déjeuner, un soin au spa, une boisson au bar, Mews l'enregistre. Il enregistre également chaque paiement entrant (espèces, carte, en ligne, city ledger, etc.). Tout cela est organisé dans le Mews Accounting Report, que Omniboost lit chaque jour pour créer vos écritures comptables.

## Le rôle d'Omniboost avec Mews

Omniboost est le partenaire d'intégration principal de Mews. Presque toutes les intégrations comptables que vous voyez dans le Mews Marketplace sont construites et gérées par Omniboost. Le rôle d'Omniboost est de transférer vos données de Mews vers votre système comptable. Il ne gère pas la configuration de Mews lui-même. Toutes les modifications nécessaires dans Mews doivent être effectuées directement par l'hôtel.

## Comment trouver une intégration Omniboost dans Mews

Dans le Mews Marketplace, regardez la description sous le nom d'une connexion. Si elle indique Omniboost, cette intégration est gérée par Omniboost. Pour en démarrer une : connectez-vous à Mews, allez dans Marketplace, puis Accounting, trouvez votre système comptable, cliquez sur Explore et demandez la connexion. Omniboost vous enverra ensuite un e-mail d'intégration.

## Un réglage essentiel : désactiver Receivable Tracking

Avant d'activer une intégration Omniboost, vous devez désactiver Receivable Tracking dans Mews. S'il reste activé, Mews et Omniboost tenteront tous les deux de créer des factures, et vous vous retrouverez avec des doublons dans votre système comptable. Où le trouver : Menu Mews, puis Settings, puis Property, puis Finance, puis Accounting Configuration, puis désactivez Receivable Tracking.

## Intégration POS vers Mews

Si votre établissement utilise un point de vente (restaurant, bar, spa), Omniboost peut aussi le connecter à Mews :

- **Room Charge**:le revenu du POS est directement facturé au profil d'un client dans Mews en utilisant son nom ou son numéro de chambre. Le client règle la facture au checkout plutôt qu'au POS.
- **Check Closure**:une addition peut être clôturée avec le moyen de paiement Room Charge sans exiger un paiement immédiat sur le terminal POS.
- **Guest Lookup**:le personnel peut rechercher des clients dans Mews par nom ou numéro de chambre directement depuis le POS.
- **Consolidated Accounting Reports**:toutes les transactions POS apparaissent automatiquement dans la section Outlets du Mews Accounting Report, offrant une vue unifiée des revenus pour toute la propriété.
